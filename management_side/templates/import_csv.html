Drop your CSV file here or click to browse  •  CSV files only
Expected format — one student per row, no header row, columns in this order:
roll_no, student_name, class, section, student_gmail, DOB (YYYY-MM-DD), mobile_no

Roll numbers already in the system will be updated; new roll numbers will be added as new students. If a row leaves class or section blank, the values selected above are used instead.
